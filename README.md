## 🚀 Funcionalidades

- **Operações Básicas:** Soma, subtração, multiplicação e divisão.
- **Display LCD:** Interface que simula as calculadoras digitais antigas.
- **Design Slin & Responsivo:** Interface limpa, moderna e adaptável.
- **Histórico de Operação:** Visualize a conta anterior logo acima do resultado atual.
- **Correção em Tempo Real:** Botão `DEL` para apagar o último dígito e `AC` para limpar tudo.

## 🎨 Design & Estética

O foco principal deste projeto foi a fidelidade visual:
* **Fonte Digital:** Utilização da tipografia *Orbitron* para simular os "segmentos de 8" das calculadoras reais.
* **Neumorfismo:** Botões com profundidade e feedback visual ao clicar.
* **Esquema de Cores:** Fundo escuro contrastando com o display verde clássico.
